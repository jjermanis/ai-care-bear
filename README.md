# ai-care-bear
Reenactment of my Atari 1200 from the 80's


## Overview
You are a Care Bear. Capture all the treasures. Avoid all the traps.

## Description
You control the Care Bear. They start at the bottom-center of the screen. Use the arrow keys to control the movement of the Bear. Hold arrows down to move in that direction.

Treasures are the pink squares. There are 20 treasures - catch them all! Traps are the gray squares. There are 10 traps. If you touch one of those traps, the game is over.


## Details
This is my attempt to recreate a game I implemented by in the mid 80's on an Atari 1200. That game on the 1200 was implemented by me by scratch.

This version was purely created from memory of the original game.
